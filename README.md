# 理解 Python 的 GIL 与并发编程陷阱

**核心概念**：GIL（Global Interpreter Lock，全局解释器锁）是 CPython 解释器中的机制，保证同一时刻只有一个线程在执行 Python 字节码。

**性能表现与应对**：

* **CPU 密集型任务**（如图像处理、矩阵计算）：
* 多线程不仅无法利用多核 CPU，反而因线程切换开销导致变慢。
* **解决方案**：使用 `multiprocessing` 多进程模块，或将计算交由 C/C++ 扩展（如 NumPy）。


* **IO 密集型任务**（如网络请求、文件读写）：
* 线程在等待 IO 时会释放 GIL，因此多线程依然有效。
* **更优解**：采用 `asyncio` 协程架构，利用单线程异步事件循环实现极高的并发吞吐。
